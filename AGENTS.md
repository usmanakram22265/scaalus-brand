# Scaalus brand system — agent guide

All agent instructions live in [`SKILL.md`](SKILL.md) (the Claude skill `scaalus-brand`). Read that first, then `business.json` (the message) and `dist/brand.json` (the colours).

**Elements, not visuals:** take the message rules, colours, gradients and logo rules from here. Write every line of copy and design every visual yourself, fresh every time, and always say the result, never the service.

**Don't edit these files** unless the user is working in the main repo and asks for a change.
